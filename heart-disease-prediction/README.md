# ❤️ Heart Disease Prediction System

A comprehensive machine learning web application for predicting heart disease risk based on clinical parameters.

## 🚀 Features

- **🔍 Accurate Prediction**: 86.9% accurate Random Forest model
- **📊 Interactive Dashboard**: Real-time data visualizations
- **💾 Data Management**: SQLite database for prediction history
- **🎯 Risk Assessment**: Comprehensive risk categorization
- **📈 Analytics**: Model performance and feature analysis
- **🩺 Clinical Reference**: Parameter interpretation guide
